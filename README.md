## Projects

* [computer-vision-scraper-yolov4](https://github.com/Slamwise/computer-vision-scraper-yolov4).
  A YOLOv4 detection pipeline I trained and ran end to end. These are the same

  in plain language and it gives you back a bill of materials and a cost
