## Featured Projects

**[MaterialDiscovery](https://github.com/Slamwise/MaterialDiscovery)** -- Active-learning materials discovery platform using Bayesian optimization, MACE neural network potentials, and Green-Kubo molecular dynamics to find novel ultra-high temperature ceramics for aerospace and fusion applications. `Active`

**[aiEngineer](https://github.com/Slamwise/aiEngineer)** -- Full-stack manufacturing cost estimation platform (React + TypeScript + Express + PostgreSQL) with multi-agent AI orchestration that routes project descriptions through specialist engineering agents to produce Bills of Materials and cost breakdowns. `Active`

**[nuclear-projects](https://github.com/Slamwise/nuclear-projects)** -- Monte Carlo neutron transport simulation of a TRISO-fueled hexagonal reactor core using OpenMC, modeling fuel particles through full core assembly with criticality analysis. `In Progress`

**[Backtesting](https://github.com/Slamwise/Backtesting)** -- Trading strategy backtesting engine paired with YOLOv8 computer vision for real-time chart pattern detection on live Kraken BTC streams and recorded market video. `Prototype`

**[Trading-Pattern-Detection](https://github.com/Slamwise/Trading-Pattern-Detection)** -- Automated stock screener and algorithmic pattern detector (H-pattern, 30-min pivot) connected to Interactive Brokers TWS with SQLite signal persistence. `Prototype`
